一、容器内调 AI 失败:四层测试,断在 TLS

自下而上分层排查——哪一层断,就在哪一层修。目标服务:dashscope.aliyuncs.com(百炼 API)。

  1. DNS域名能解析成 IP 吗
    getent hosts dashscope.aliyuncs.com 解析成功 · 4 个 IP
  2. TCP443 端口握得上手吗
    echo > /dev/tcp/dashscope.aliyuncs.com/443 握手成功
  3. TLS加密握手能完成吗
    wget -O- https://dashscope.aliyuncs.com Connection reset
轨道到此中断。 流量没能走出容器——请求从未到达 HTTP 层,这就是「创建面试失败」的根因层。
